## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI tick/process boundary → HKLM/HKCU registry | Ticked rows cross into admin registry writes via Footprint-declared keys only |
| In-memory entries → gaming-journal.json on disk | Journal file is the revert authority; corrupt or hostile content must degrade safely |
| Elevated process → interactive-user HKCU hive | GameBar/DVR keys may live under the real user hive, not the elevation account hive |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-02 | Tampering | GamingJournal load/replay | medium | mitigate | Typed schema with version field, old versions ignored with warning, corrupt file degrades to empty journal per FileSettingsStorage rule, never throws into navigation |

<objective>
Complete the Cleanup category's final 3 actions — the D-03/D-06/D-08 script replacements — by extracting single non-interactive branches from the three canonical "Ultimate" collection scripts (`13 Bloatware.ps1`, `20 Edge & WebView.ps1`, `10 Edge Settings.ps1`) into 6 standalone embedded `.ps1` files, following the exact extraction technique Phase 2's D-06 scripts pioneered (strip self-elevation/menu scaffolding, keep the chosen branch's body only) plus this phase's own RESEARCH.md-documented fixes for 2 hang risks (Pitfalls 1-2) specific to these 3 source scripts. This closes out DEBLOAT-01's full 28-action set.

This is the highest-risk plan in the phase: `13 Bloatware.ps1`'s branches 2 and 4 loop back into their source script's interactive menu via a trailing `show-menu` call (Pitfall 1) instead of exiting, and all three source scripts share a `Pause`-guarded internet-connectivity pre-flight check (Pitfall 2) — both call `Read-Host` internally, which blocks forever against `IScriptRunner`'s non-redirected-stdin child process (`ScriptRunner.cs`'s `ProcessStartInfo` sets `RedirectStandardOutput`/`RedirectStandardError` but never `RedirectStandardInput`). Both risks are fixed identically in every extracted file: replace the trailing `show-menu` (Bloatware only) with a bare `exit`, and replace `Pause` (all 3 sources) with nothing, changing the connectivity-check's `exit` to `exit 1`.

Per D-03, `bloatware-remove.ps1`/`bloatware-installall.ps1` also preserve the pre-menu `DevicePasswordLessBuildVersion` registry write (source line 22, executed unconditionally before any menu choice — Pitfall 3, easy to drop by only copying the numbered `case` block). Per D-06/D-07, `edgewebview-uninstall.ps1` ports its `.\reg1.exe` relative-working-directory write as-authored without rewriting to an absolute path (Pitfall 4 — flagged for manual smoke-test attention, not a code change, since the app's own working directory is generally writable while elevated). Per D-07, this plan also records the deliberate, already-approved override of REQUIREMENTS.md's "Full removal of ... WebView2 ..." Out-of-Scope entry — a documentation-only edit CONTEXT.md flagged as outstanding.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Elevation of Privilege | ScriptRunner.RunProcessAsync | high | mitigate | Only Phase-1-internal call sites (Plans 01-05/01-06) invoke this primitive with hardcoded `fileName`/`arguments`; no external or user-supplied input reaches `RunProcessAsync` in this phase — flagged high because the primitive itself has no allowlist, so a future phase adding a free-text-driven call site MUST NOT do so without revisiting this threat |
| T-01-06 | Denial of Service | ScriptRunner timeout handling | low | mitigate | `Task.WhenAny` + `process.Kill(entireProcessTree: true)` on timeout expiry prevents a hung child process from blocking the app indefinitely |
| T-01-07 | Information Disclosure | ILogConsoleService.Lines rendering raw stdout/stderr | low | accept | Log content is local-machine process output shown to the same elevated local user who invoked the action; no network transmission of log content in Phase 1 |

## Flagged Assumptions (edge-probe items resolved as inapplicable, not force-fit)

- **APP-05 adjacency** ("when two things are exactly equal or just touch, do they merge, collide, or separate?"): does not map onto three independent primitive services (log console, service controller, script runner) — there is no merge/collision concept between them; resolved as inapplicable.
- **APP-05 empty/null input**: `ILogConsoleService.Log("")` is a valid, allowed call — it appends an empty line, matching the predecessor's `TxtLog.AppendText` behavior for blank lines; no special-case rejection is needed, so this is not a probe gap requiring a new predicate.
- **APP-05 ordering**: `Log` calls append in call order because `DispatcherQueue.TryEnqueue` preserves FIFO order for work items enqueued on the same dispatcher — no ambiguity exists to resolve with an additional test.
- **APP-05 encoding**: `IScriptRunner`'s captured process output uses `StandardOutputEncoding`/`StandardErrorEncoding = Encoding.UTF8` (ported verbatim from `ToolService.cs`) — no additional encoding-ambiguity surface is introduced by this plan's primitives.
- De facto prohibition coverage: this plan's `prohibitions` entry (no silent-swallow of failures) is directly enforced by Task 3's acceptance criteria (`RunProcessAsync` streams every captured line to `ILogConsoleService`, the `Debug.WriteLine` placeholder is replaced) — functioning as the concrete edge-check this probe-less phase otherwise lacks a SPEC.md to derive from.

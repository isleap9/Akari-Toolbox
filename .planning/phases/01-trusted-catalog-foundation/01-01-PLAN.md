## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-toggle→registry | Row toggle crosses into HKLM/HKCU writes via TweakAction native ops under the admin manifest |
| search-text→filter | Untrusted keystrokes enter the in-memory title filter only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Game DVR HKCU writes in GamingCatalog seed rows | high | mitigate | Route every interactive-user HKCU write through AkariToolState RealHkcu helpers and verify with post-apply RefreshFromSystem read-back in the per-row runner |
| T-01-02 | Tampering | Multi-value row partial apply | medium | mitigate | Derive pills from RefreshFromSystem read-back after every apply, never from the requested target; failure path rolls the control back to live state |
| T-01-03 | Information disclosure | Registry footprint display in Technical-details expander | low | accept | Footprint is read-only text plus optional Open in Registry Editor; pills re-probe live state on every navigation so hand-edit divergence self-corrects |
| T-01-SC | Tampering | package installs | high | mitigate | No package-manager installs in this phase (Windows App SDK first-party controls only); any future install needs a legitimacy audit plus blocking human checkpoint |
</threat_model>

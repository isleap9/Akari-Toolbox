# Phase 01 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Stack note:** This is a WinUI 3 desktop app (.NET 10, Windows App SDK 2.3.1) — NOT React/Next.js/Vite. The shadcn gate resolves to N/A. The "design system" is native WinUI styling: system theme resources, native text styles, `Spacing`/`ColumnSpacing` layout. No custom theme dictionaries, no hardcoded colors (per project conventions and `Views/Shared/PageStyles.xaml`). `Tool: none`; the Component Inventory section is omitted per template rules.

**Binding design bar (highest priority after CONTEXT.md):** `.planning/research/winhance-patterns.md` §6 — row = title + ONE description line + badge pills + live control; per-row Recommended/Default quick-set pair; Technical-details expander collapsed by default; grouped sections + search + empty state; per-row status feedback via card-attached strip, never a modal.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (native WinUI 3 — shadcn N/A, not a web project) |
| Preset | not applicable |

**Reusable XAML (already in repo, extend — do not duplicate):**

| Style key | Source | Use for this phase |
|-----------|--------|--------------------|

| `AkariCardTitle` | `Views/Shared/PageStyles.xaml` | Row title: native Body + SemiBold + `CharacterEllipsis` |
| `AkariCardDescription` | `Views/Shared/PageStyles.xaml` | Row one-liner: native Body, secondary fill, wrapped |
| `AkariSectionHeader` | `Views/Shared/PageStyles.xaml` | Group headers (System / Network / GPU / Background): native Subtitle, top margin 8 |
| `AkariCaption` | `Views/Shared/PageStyles.xaml` | Expander internals, registry paths (monospace override allowed ONLY for path/value text: Consolas, selectable), hints |
| `AkariPageMargin` | `Views/Shared/PageStyles.xaml` | Page gutter thickness 32,32,32,32 |

**XAML hard rules (project conventions, non-negotiable):**

1. Page root uses `{Binding}` with `DataContext = ViewModel` — page-level `x:Bind` dies with WMC9999.
2. `x:Bind` only inside `DataTemplate` with `x:DataType` — all row interactivity (toggle, quick-set buttons, expander) binds to commands living on the row item class (`CatalogRowItem`-style, mirroring `CpRowItem` in `TweaksViewModel.cs`); never `RelativeSource AncestorType`.
3. `ToggleSwitch` rows set `MinWidth="0"`.
4. `InvertedBooleanConverter` for `x:Bind` negation (no negation operator exists); `MainWindow` shell must use `x:Bind` function bindings, never `IValueConverter` lookup.
5. Per-row busy state only — never page-wide `IsBusy` for a single row's apply (precedent: `TweaksViewModel.SetRowsBusy`).

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Badge-pill internal padding, icon-to-text gaps |
| sm | 8px | Section-header top margin (`AkariSectionHeader`), compact intra-row gaps, quick-set button pair gap |
| md | 16px | Card padding (`AkariCard`), default `Spacing` between row cards in a group |
| lg | 24px | Group-to-group vertical gap (between System / Network / GPU / Background sections) |
| xl | 32px | Page gutter (`AkariPageMargin`: 32 on all sides) |
| 2xl | 48px | Reserved — page-level breaks if the catalog grows a hero/header zone (do not use yet) |
| 3xl | 64px | Reserved — not used in this phase |

Exceptions: `ToggleSwitch` touch target follows the native control size (do not force to the scale); registry-path text inside the expander uses 12px caption leading independent of the scale.

**Row card internal layout (binding):** Title line (left) + live control (`ToggleSwitch`, right, `MinWidth="0"`); ONE description line below the title (`AkariCardDescription`, single gamer-language sentence — never a paragraph stack); badge-pill row (`Recommended` / `Default` / `Custom` + `Restart required` where applicable) under the description; quick-set pair (green "Set to Recommended" + grey "Set to Default", small buttons, tooltips naming target values) preceding the control; slim Technical-details bar (info icon + "Technical details" + chevron, collapsed by default) attached below the card face. Applying state: `ProgressRing` overlay on the card (`IsApplying`); compatibility/restart/value notices: quiet `InfoBar` strip attached below the card (`HasStatusBanner`) — never a modal.

## Typography

Native WinUI text styles only — sizes are the platform ramp, not custom tokens:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`BodyTextBlockStyle` — row title, one-liner) | Regular (400); SemiBold (600) for row titles only (`AkariCardTitle`) | 1.5 (native default; do not override) |
| Label | 12px (`CaptionTextBlockStyle` — badge pills, expander internals, hints, registry paths) | Regular (400); SemiBold (600) for badge-pill text only | 1.33 (native default; do not override) |
| Heading | 20px (`SubtitleTextBlockStyle` — group section headers `System` / `Network` / `GPU` / `Background`) | SemiBold (600) | 1.2 (native default; do not override) |
| Display | 28px (`TitleTextBlockStyle` — page title only, e.g. "Gaming Catalog") | SemiBold (600) | 1.2 (native default; do not override) |

Exactly 4 sizes (12, 14, 20, 28), exactly 2 weights (400 + 600). Registry paths/value names inside the expander render in Consolas 12px, selectable (`IsTextSelectionEnabled="True"`). Row titles use `TextTrimming="CharacterEllipsis"`; the one-liner wraps (max 2 visual lines — if copy exceeds that, shorten the copy, never grow the card face).

## Color

No hex values — every brush is a system theme resource so light / dark / high-contrast all follow the OS. The 60/30/10 split is expressed in surfaces:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `{ThemeResource ApplicationPageBackgroundThemeBrush}` (+ `LayerFillColorDefaultBrush` for page chrome) | Page background, app surfaces |
| Secondary (30%) | `{ThemeResource CardBackgroundFillColorDefaultBrush}` + `{ThemeResource CardStrokeColorDefaultBrush}` (via `AkariCard`) | Row cards, group containers, Technical-details expander surface |
| Accent (10%) | System accent (`{ThemeResource SystemAccentColor}`-derived default button / `ToggleSwitch` on-state fills) | Accent reserved for: (1) `ToggleSwitch` on-state fill, (2) "Set to Recommended" button fill (default-button style, glyph E735), (3) `Recommended` badge-pill fill, (4) search-box focus underline / suggestion highlight |
| Destructive | `{ThemeResource SystemFillColorCriticalBrush}` (declared only) | Destructive actions only — **none exist in this phase** (per-row revert restores prior/Default values and is fully reversible, so it is NOT styled destructive; "Set to Default" is a neutral grey button) |

Accent reserved for: ToggleSwitch on-state, "Set to Recommended" button, Recommended badge pill, search focus/suggestion highlight. Accent is NEVER used for: body text, card borders, the "Set to Default" button, expander chrome, InfoBar strips (those use their native severity brushes).

**Text fills:** Primary text `{ThemeResource TextFillColorPrimaryBrush}` (default — do not set explicitly); one-liner/description `{ThemeResource TextFillColorSecondaryBrush}` (via `AkariCardDescription`); badge-pill dimmed state uses disabled/secondary fills to signal non-matching state. Reboot-required pill uses the system warning brush (`SystemFillColorCautionBrush`-family) as fill or glyph — in place on the card, never segregated, never blocking (D-13).

## Copywriting Contract

Voice: plain gamer language on the card face (Winhance style — "Optimize your PC for play by turning things off in the background"); precise technical language inside the Technical-details expander. Every one-liner is ONE sentence describing what-it-does. What / why-it-helps-gaming / risk / how-it-reverts live behind the expander (BRW-02). Quick-set tooltips MUST name the target value (D-06, e.g. "Recommended: On (HwSchMode=2)").

| Element | Copy |
|---------|------|
| Primary CTA (per row) | "Set to Recommended" (green/default-button style, glyph E735, tooltip names the recommended value) |
| Secondary CTA (per row) | "Set to Default" (neutral grey button, tooltip names the Windows-default value) |
| Expander label | "Technical details" (info icon + chevron; collapsed by default; expands to registry footprint rows with Current / Recommended / Default side-by-side + "Open in Registry Editor" button) |
| Page title | "Gaming Catalog" (`TitleTextBlockStyle`, 28px) |
| Search placeholder | "Search tweaks" (title-only matching; suggestions appear from the first character, prefix-first, max 8, tap-to-filter never applies) |
| Group headers | "System" / "Network" / "GPU" / "Background" |
| Empty state heading | "No matching tweaks" |
| Empty state body | "Try a different search — matching is by tweak title only." |
| Row applying | Card-attached `ProgressRing` overlay; no text (shell status footer shows "{Title}…" via `IStatusService.Start`) |
| Success state | InfoBar: "{Title} applied" + note (e.g. "Restart to apply" for `RequiresReboot` rows — badge + note, never blocking) |
| Error state | InfoBar: "{Title} failed" + exception message as the second line; the row control is rolled back to its live read-back state so it never lies; next step is retry or "Set to Default". Never surface stack traces. |
| Restore-point offer (first apply per session) | Dialog title: "Create a restore point?"; body: "This saves a system restore point before your first tweak is applied. You can skip this — every tweak can still be reverted from its own row."; buttons: "Create restore point" / "Skip". Creation failure warns via InfoBar ("Restore point skipped" + reason) and the apply proceeds regardless — offer, never gate (D-09). |
| Restart-required badge | Pill copy: "Restart required" |
| State pills | "Recommended" / "Default" / "Custom" (diverged) — reflect live read-back on every navigation and every apply, never cached optimism (D-07) |
| Destructive confirmation | N/A — no destructive actions in this phase. Per-row revert is instant and non-confirmed (it restores prior/Default values, fully reversible by re-applying). |

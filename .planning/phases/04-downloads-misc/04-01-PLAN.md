## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| App -> winget CLI | This app invokes `winget install` with a compiled-in package ID string per catalog row — no user-typed input reaches the process arguments |
| App -> GitHub raw content (PostInstall mirror) | HTTPS GET against a pinned repo path, no user input in the URL |
| App -> Windows Registry / filesystem | Elevated process writing to `C:\PostInstall\` and invoking `winget.exe`/`powershell.exe` child processes |

| T-04-03 | Denial of Service | `AppInstallerService.InstallAsync` (non-zero exit code swallowed) | medium | mitigate | This plan fixes the predecessor's swallowed-exit-code bug — a failed install now returns `false` and is logged, not silently treated as success |
